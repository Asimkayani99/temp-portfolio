# Asim Kayani — Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Features
- Sticky navigation bar with smooth in-page links (About, Projects, Contact)
- Dark / Light mode toggle (JavaScript + CSS variables)
- Featured projects section: A.K Shopping House, Library Management System (C# console application), FitFlow DAILY branding
- Interactive contact section (click "Say Hello" to reveal contact details)
- Fully responsive layout for mobile and desktop

## Files
- `index.html` — page structure and content
- `style.css` — styling, theme variables, responsive media queries
- `script.js` — dark-mode toggle and contact reveal interactivity
